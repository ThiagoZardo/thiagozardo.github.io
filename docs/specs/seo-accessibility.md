# SEO & Accessibility

## SEO

- Localized title/description for PT and EN.
- Canonical and hreflang alternates include x-default.
- Person schema describes role, skills, location and professional profiles.
- Sitemap contains root, PT and EN routes.
- Open Graph and Twitter copy match the new positioning.
- Static export and trailing-slash URLs remain compatible with GitHub Pages.

## Accessibility

- Skip link, semantic header/nav/main/sections/footer.
- A single descriptive H1; section H2 and card H3 hierarchy.
- Visible focus ring on all controls.
- Language switch has an accessible label and current-page indication.
- External links declare safe rel values and understandable names.
- Decorative graphics are CSS-only and hidden from assistive technology.
- Reduced-motion media query disables smooth scrolling and animation.
