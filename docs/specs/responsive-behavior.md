# Responsive Behavior

- 320–430: single-column flow, wrapped header controls, 44px interactive targets, hero title uses fluid sizing, case metadata stacks, troubleshooting chain scrolls/wraps without page overflow.
- 768: two-column evidence and stack group layouts; navigation remains compact.
- 1024+: full navigation, asymmetric hero and experience grids, alternating case layouts.
- 1440–1920: content width remains capped; whitespace grows rather than text line length.
- No fixed content heights. Anchors use scroll margin below the sticky header.
- Validation viewports: 320, 375, 390, 430, 768, 1024, 1440, 1920.
